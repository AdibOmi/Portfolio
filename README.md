# Adib Ahmed — Portfolio

Built with React + Vite + Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

## Customization Checklist

### Content
- [ ] Update `src/data.js` with real project descriptions, GitHub links, and live demo URLs
- [ ] Update LinkedIn URL in `src/data.js` (about.linkedin)

### Images
Add your images to `/public/images/`:
- `adib.jpg` — your photo (used in About section)
- `gainframe.png` — Gainframe screenshot
- `crowd-control.png` — Crowd Control screenshot
- `deja-view.png` — Deja View screenshot
- `pump-fiction.png` — Pump Fiction screenshot

### Deployment (Vercel — recommended)
1. Push to GitHub
2. Go to vercel.com → Import project
3. Select your repo → Deploy
4. Done. Free hosting, auto-deploys on push.

## Stack
- React 18
- Vite
- Framer Motion (animations)
- Lucide React (icons)
- CSS Modules (styling)
